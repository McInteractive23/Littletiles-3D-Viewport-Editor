3D Preview

Left-click a box to select it (drag for a selection box, Shift-click to add more). Middle-click drag to orbit, shift + middle-click drag to pan, scroll to zoom — see 🎮 Controls in the header for the full list and hotkeys. Each box is colored using its own color/alpha, and corner offsets bend the box the same way LittleTiles' transformable corners do. Flipping a face reverses its stored triangle winding (so the exported data is correct) but every face still renders solid here — nothing goes invisible in the preview. The floor grid is spaced to the selected Grid value, so each square is one in-game block.
