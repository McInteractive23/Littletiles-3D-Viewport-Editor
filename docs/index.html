3D Preview

Drag to orbit, scroll to zoom, middle-click drag to pan. Each box is colored using its own color/alpha, and corner offsets bend the box the same way LittleTiles' transformable corners do. Flipping a face reverses its stored triangle winding (so the exported data is correct) but every face still renders solid here — nothing goes invisible in the preview. The floor grid is spaced to the selected Grid value, so each square is one in-game block.
